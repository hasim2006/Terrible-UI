## 🎯 About The Project

**TERRIBLE UI** is a satirical web application engineered with a paradox in mind:
- **10/10 Visual Design:** Dark glassmorphism, electric neon purple & green accents, sleek typography, micro-interactions, and fluid Framer Motion animations.
- **2/10 Usability:** Intentionally hilarious, inconvenient, and unpredictable anti-patterns that test user patience while maintaining 100% bug-free technical stability.
- **10/10 Engineering:** Built on Next.js 16 (Turbopack), React 19, TypeScript, Tailwind CSS v4, and the Web Audio API.

## ✨ Features & Disaster Gallery

### 1. 🎈 Pop The Balloon (`/pop-the-balloon`)
A frantic mini-game where a glossy neon balloon calculates cursor vector proximity and aggressively dodges your pointer, fakes popping, and panics across 5 difficulty levels (*Normal*, *Worse*, *Terrible*, *Absolutely Unfair*, *Why*).

### 2. 🖱️ The Button Lab (`/button-lab`)
Over 25+ engineered bad UX buttons:
- **Submit:** Does absolutely nothing.
- **Cancel:** Submits your data immediately.
- **Download:** Reaches 99% then announces *"Download failed because you clicked Download"*.
- **Yes / No:** YES expands exponentially on every click while NO shrinks to microscopic sizes.
- **Refresh:** Rotates the entire viewport 180 degrees.
- **Light Theme:** Flashbangs the screen with a blinding white overlay.
- **Schrödinger's Button:** Only changes state when your cursor leaves.

### 3. 📝 The Simple Form (`/form`)
A 10-field form with unhinged validation criteria:
- Valid Email $\rightarrow$ *"Email is suspiciously valid."*
- Strong Password $\rightarrow$ *"Password is too strong."*
- Checkbox that un-checks itself when you click it.
- Final submission: *"REGISTRATION FAILED SUCCESSFULLY: Perfect inputs are disallowed."*

### 4. 🗂️ Popup Hell (`/popup-hell`)
A 5-layer deep confirmation labyrinth testing if you really, truly, absolutely want to proceed.

### 5. 🤖 BadGPT AI (`/badgpt`)
A sarcastic, unhelpful AI companion that mocks your queries with 35+ dry, witty responses and an evasive modal widget.

### 6. 📊 Dashboard (`/dashboard`)
Real-time fake telemetry tracking User Happiness steadily plunging from 87% to 12%, paired with bad decision metrics.

### 7. ⚙️ Terrible Settings (`/settings`)
Controls that do the exact opposite of what you ask:
- Turning dark mode off makes the screen darker (*"Darkness increased"*).
- Lowering confusion resets it straight to 100% MAXIMUM.

### 8. 🕵️ Classified Secret Route (`/secret`)
Matrix-style green CRT terminal with confidential warnings and an "Erase Evidence" button.

### 9. 🏆 Achievements & Easter Eggs
- 14+ unlockable achievements saved in LocalStorage (e.g., *Button Victim*, *Popup Survivor*, *Konami Master*, *Final Boss*).
- 15 hidden Easter eggs including Konami code (`↑ ↑ ↓ ↓ ← → ← → B A`), typing "terrible", and clicking logos.
- Built-in retro Web Audio API synthesizer for 8-bit sound effects.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ (Node.js 20+ recommended)
- npm or yarn or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hasim2006/Terrible-UI.git
   cd Terrible-UI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open **[http://localhost:3000](http://localhost:3000)** in your browser!
