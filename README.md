# Terrible UI 🤪

> **Beautifully designed. Horribly usable.**  
> What happens when you combine top-tier UI/UX design with the worst possible user experience on purpose.

🌐 **Live Demo:** [terrible-ui.vercel.app](https://sih-project-one-cyan.vercel.app/)

---

### What is this?

A satirical web app featuring **10/10 visual design** with **2/10 usability**. Everything looks like it came from an elite design team (dark glassmorphism, neon glows, fluid Framer Motion animations), but behaves like a total disaster.

It's fast, responsive, and completely bug-free — every annoying UX decision is 100% intentional.

### Some "features" you'll hate:

- 🎈 **Pop The Balloon:** A mini-game where the balloon actively calculates your cursor trajectory and dodges it, fakes popping, and panics across 5 difficulty levels.
- 🖱️ **Button Lab:** 25+ anti-UX buttons — `Submit` does nothing, `Cancel` submits, `Refresh` rotates the whole screen 180°, and `Download` fails at 99%.
- 📝 **The Simple Form:** A form that complains your email is *"suspiciously valid"* and unchecks checkboxes by itself.
- 🤖 **BadGPT:** An AI assistant that exists solely to give sarcastic, unhelpful answers.
- 🗂️ **Popup Hell:** Modals inside modals asking if you're *really* sure.
- ⚙️ **Terrible Settings:** Turning dark mode off makes your screen even darker.

Also features 14+ unlockable achievements, a floating **Bad Decisions** counter, 15 Easter eggs (including the Konami code), and retro 8-bit sound effects synthesised in real-time with Web Audio API.

### Tech Stack
- Next.js 16 (Turbopack) & React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Web Audio API

### Run Locally

```bash
git clone https://github.com/hasim2006/Terrible-UI.git
cd Terrible-UI
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and enjoy the chaos.
